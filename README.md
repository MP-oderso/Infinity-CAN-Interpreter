# Infinity-CAN-Interpreter
In Pfusch we trust

Das Projekt soll die Testdaten von den letzten Fahrten des Elektrisch betriebenen Formula Student Autos von Infinity Racing benutzen und auswerten.
Dazu sollen die vom Can ausgelesenen Daten interpretiert werden und in eine visuelle und/oder Gut lesbare Oberfläche dargestellt werden,
damit diese ausgewertet werden können.
